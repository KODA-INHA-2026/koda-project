# KODA Proof — 역할별 증빙 데모

현재 팀 공유본 (2026-11-03): https://koda-inha-2026.github.io/koda-project/draft-20261103/

이전 초안 (2026-11-02): https://koda-inha-2026.github.io/koda-project/draft-20261102/

v0.3 재현본: https://koda-inha-2026.github.io/koda-project/

현재 개선안은 `apps/web/src/experience/Experience.tsx`에서 시작합니다. KODA → 고객사 재무 → 고객사 회계 → 외부 감사 순서로, 사용자 업무 화면과 화면 뒤 처리 과정을 나란히 보여줍니다.

## 실행

Node 24.16.0, npm 11을 사용합니다.

```bash
npm install
npm run dev:proof
```

<http://localhost:5186>에서 확인합니다. 이미 실행 중인 서버가 있으면 재사용합니다.

## 시연 흐름

1. KODA: 잔고 증빙 발행, 발행자 서명과 문서 지문 기록을 모의 시연합니다.
2. 재무: 매입 내역·내부 승인·수탁 잔고의 대조 여부를 체크하고 회계팀에 전달합니다.
3. 회계: 확인한 증빙을 3분기 결산 자료에 연결합니다.
4. 회계: 감사인의 DID와 만료일을 기준으로 열람 권한을 전달합니다.
5. 외부 감사: 원본 전체를 열고 원본 PDF의 SHA-256을 기준 기록과 비교합니다.
6. 외부 감사: 원본·수정본·재저장 사본 또는 직접 선택한 PDF를 검사합니다.

상단 단계와 좌우 방향키로 장면을 자유롭게 이동할 수 있습니다. 이전 단계를 건너뛰면 가정한 미리보기 상태를 표시합니다. 재무·회계의 열람 범위는 같고 업무를 구분했습니다. 역할 분리와 결산 연결은 사용자 요청 및 발표 슬라이드를 바탕으로 추가한 UX 제안입니다.

공개 기록 조회, 역할별 열람 범위, 원본 상세, 활동 기록은 보조 창에서 확인합니다. 시연 상태는 새로고침하면 초기화되고 선택한 장면은 URL에 유지됩니다.

## 검증

```bash
npm run build:proof:pages
npm run test:proof
```

브라우저 테스트는 개발 서버가 실행 중이어야 합니다. 기존 v0.3 재현 코드는 `apps/web/src/proof/`에 보존되어 있으며, 공통 파일 지문 계산과 시연 PDF는 새 화면에서도 활용합니다.

시연 파일은 `apps/web/public/proof-files/`, 수정하지 않은 원본 HTML은 `docs/reference/koda-v03.html`에 있습니다. `docs`의 이전 개발 문서는 사용자 요청으로 정리했습니다.

## 시연 범위

법인·자산·주소·거래·블록 번호는 모두 가상입니다. PDF 지문은 실제로 계산하지만 DID 인증·서명·권한·체인 기록·자료 전달·결산 연결은 브라우저 내 모의 처리입니다. 파일은 서버로 업로드하지 않습니다. 지원되지 않는 PDF는 내용 비교 불가로 표시하며 지문 차이만으로 위변조를 단정하지 않습니다.

## 배포

공유 사이트는 `gh-pages`의 정적 산출물이며, 로컬 수정이나 개발 브랜치 push만으로 바뀌지 않습니다. `npm run build:proof:pages`의 결과는 `apps/web/dist`입니다. 검토한 버전을 공유할 때 해당 산출물을 명시적으로 배포합니다.

2026-11-03 공유본은 옅은 민트 UI와 입체 선 도식, 원본 일치·수정본 불일치·재저장 사본 구분을 반영했습니다. 해당 경로 빌드는 아래 명령을 사용합니다.

```bash
npm run build:protocol
npm run build -w @koda/web -- --base=/koda-project/draft-20261103/
```
