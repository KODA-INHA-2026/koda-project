# KODA × INHA 2026

인하대학교 디지털자산 마이크로디그리 KODA 산학 프로젝트 학생팀의 공동 개발 저장소입니다.
제안 서비스의 시연과 프로토타입을 준비하는 공간이며, KODA나 인하대학교의 공식 운영 시스템 저장소가 아닙니다.

## 현재 상태

- GitHub 기본 협업 공간을 준비하는 단계입니다.
- 개발 소요는 정리·공유 후 기능별 범위와 담당을 확정합니다.
- 가상 고객 시나리오를 이용해 제안 서비스의 사용 모습을 보여주는 데모를 준비합니다.
- 기술 스택과 공통 실행환경은 아직 확정하지 않았습니다.
- 현재 이 저장소에는 안내 문서만 있으며, 실행 가능한 앱이나 검증 기능은 아직 없습니다.

시연에서는 실제로 구현한 기능, 가상 데이터로 처리한 부분, 목업, 추후 구현 계획을 구분합니다.

## 개발환경과 실행 방법

현재 실행할 앱과 설치 명령은 없습니다. 개발 소요와 사용할 코드·도구가 정리되면 아래 내용을 추가합니다.

- 필요한 도구와 버전
- 설치·실행 방법
- 가상 데이터 준비 방법
- 동작 확인·테스트 방법
- 실제 구현과 목업·가상 처리의 구분

필요가 확인되기 전에 특정 프레임워크나 ZK 도구를 선정하거나 운영 시스템 연동을 전제하지 않습니다.

## 자료·보안 기준

- 프로토타입에는 가상 고객·모의 거래 데이터를 사용하고 모의 자료임을 표시합니다.
- 실제 고객 정보, 개인키, 복구 구문, 비밀번호, API 키, 인증 토큰, 회사 내부 운영 자료는 올리지 않습니다.
- PPT·PDF·이미지·영상 등 발표 파일은 Drive에 두고 필요한 링크를 문서에 남깁니다.
- 외부 공개 범위와 라이선스는 팀에서 별도로 결정합니다.
