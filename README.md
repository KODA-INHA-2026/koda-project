# KODA Proof — PRD v0.3 증명 중심 시연

첨부된 `KODA_화면별_목업_v0.3_PRD.html`을 기준으로 만든 클릭형 데모입니다. 현재 웹 진입점은 `apps/web/src/proof/ProofDemo.tsx`입니다. 이전 화면과 API는 현재 데모에서 사용하지 않습니다.

- S-01~S-07: 역할 선택 → 모의 발행 → 마스킹 열람 → 권한 전달 → 감사인 원본 열람 → 검증 통과 → 사본 검사
- S-08: 지문·블록·발행자 DID로 조회하는 공개 모의 기록
- M-01: 역할별 마스킹 기준표
- 수정본, 재저장 사본, 원본, 내용 비교 불가 상태
- 열람 기록, 모의 권한 만료, 검증 증적 저장, 거래 12건 펼치기

## 실행

Node 24.16.0, npm 11을 사용합니다.

```bash
npm install
```

```bash
npm run dev:proof
```

<http://localhost:5186>에서 열립니다. 실행 중인 서버가 있으면 그 URL을 사용합니다. Tempo Run도 같은 웹 앱을 실행하도록 설정되어 있습니다.

화면 위 단계 버튼이나 좌우 방향키로 장면을 이동할 수 있습니다. 각 화면의 실행 버튼은 모의 상태와 기록을 갱신합니다. `처음부터 다시 시연`으로 초기화합니다. 새로고침 시 시연 상태는 초기화되며, URL의 장면 번호는 유지됩니다.

## 검증 및 백업

```bash
npm run test:proof
```

```bash
npm run build -w @koda/web
```

```bash
npm run demo:backup
```

`docs/demo-backup/index.html`을 직접 열면 PNG 9장으로 인터넷 없이 시연할 수 있습니다. 원본 참고 HTML은 `docs/reference/koda-v03.html`에 있습니다. `?shot=S-06`처럼 지정하면 화면만 1120×620 크기로 볼 수 있습니다.

시연 PDF 세 개는 `apps/web/public/proof-files/`에 있습니다. `npm run demo:proof-files`로 다시 만들 수 있습니다. 원본 바이트의 SHA-256을 실제 계산하며, 지원되는 PDF의 표시 항목을 비교해 수정본과 재저장본을 구분합니다. 읽을 수 없는 파일은 내용 비교 불가로 처리합니다. 공개 조회는 파일 지문만 계산합니다. 업로드 파일은 서버에 전송하지 않습니다.

## 시연 범위

법인·주소·문서·거래·블록 번호는 모두 가상입니다. DID 인증과 서명, 권한 및 만료, 열람 기록, 체인 기록은 브라우저 안의 모의 상태이며 실제 인증·서명·체인 네트워크·전송·운영 보안 경계가 아닙니다. 역할/장면 이동은 발표용으로 자유롭게 열려 있습니다. 감사인 전체 열람은 PRD의 시연 설정입니다. 서명과 최초 잔고의 진실성을 실제로 증명하지 않습니다.

폰트는 로컬에 포함되어 있습니다. 각 폰트의 라이선스는 `apps/web/public/fonts/*OFL.txt`에 있습니다.
