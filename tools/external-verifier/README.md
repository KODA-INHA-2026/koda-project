# KODA 외부 검증 도구 — 검토용 초안

KODA 대시보드 밖에서도 같은 PDF와 검증정보를 사용해 결과를 재현하는 **기술 검토용 패키지**입니다. KODA의 공식 제품이나 운영 배포물이 아닙니다.

## 실행

Node.js 22 이상이 필요합니다. 별도 패키지 설치나 지갑 연결은 필요하지 않습니다.

```text
node verify.mjs <증명서.pdf> <검증정보.json>
```

종료 코드는 원본 일치 `0`, PDF 불일치 `2`, 검증 미완료·오류 `1`입니다. 표준 출력의 JSON 보고서에는 판정과 실제 처리 trace가 함께 기록됩니다.

입력 경계 회귀 검사는 유효한 PDF 한 건과 포함된 JSON 예시를 사용해 실행할 수 있습니다.

```text
node check-rejections.mjs verify.mjs <유효한 증명서.pdf> example-verification.json
```

이 검사는 잘못된 실행 인자, 등록 거래 해시 누락, 임의 계약·발급자 필드, 용량 초과 JSON, PDF가 아닌 파일을 체인 조회 전에 거절하고 실행 번들에 지갑·쓰기 호출이 없는지 확인합니다.

## 신뢰 기준

- 제출 JSON은 조회 대상을 찾는 자료일 뿐, 신뢰할 발급자·컨트랙트·RPC를 지정하지 못합니다.
- 검증기는 Sepolia 체인 ID, 공개 실증 계약, 시험 발급자, 배포 거래를 코드에 고정합니다.
- PDF 전체 바이트, EIP-712 발급서명, 등록 거래 입력, 영수증·이벤트, finalized 기록을 대조합니다.

## 범위

이 패키지는 데모에서 사용한 시험 발급자와 Sepolia 기록을 검증합니다. BTC 잔고의 사실성, 공식 KODA 신원, RPC 제공자의 독립성은 증명하지 않습니다. 실제 운영에는 신뢰 목록 배포·갱신·폐기, 복수 RPC 또는 자체 노드, 버전·서명된 릴리스 정책이 추가로 필요합니다.

`verify.ts`는 사람이 읽을 수 있는 진입 코드이고, `verify.mjs`는 동일 코드를 의존성과 함께 묶은 실행 파일입니다.
