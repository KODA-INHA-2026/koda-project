# 다음 접속 때 필요한 승인

사용자가 쉬는 동안 승인 요청을 띄우지 않는다. 공개 실증 기록의 재생과 제3자 검증은 지갑 승인 없이 실행할 수 있다.

## 인하테크홀딩스㈜ 이름으로 새 증명서를 등록할 때

1. `http://127.0.0.1:5190/live.html`의 발표자 실행 준비에서 기존 Sepolia 시험 계정을 연결한다.
2. `인하테크홀딩스 증명서 발급·등록`을 누르고 MetaMask의 **EIP-712 문서 서명**을 승인한다.
3. 이어지는 **DocumentRegistry.register 등록 트랜잭션**을 승인한다. 기존 컨트랙트를 재사용하므로 재배포는 필요 없다.
4. 성공 영수증과 최종 확정을 확인한 뒤 새 PDF로 제3자 검증을 수행한다. 확정 대기 중에는 기다렸다가 다시 조회한다.

기존 한울테크홀딩스㈜ 원본 PDF·해시·서명·거래는 보존한다. 새 이름의 등록이 완료되었다고 미리 표시하지 않는다. 등록 승인을 거절했을 때는 저장된 서명 문서의 등록 재시도를 사용할 수 있다.

## 이번 변경으로 추가 승인이 필요하지 않은 일

발표 전체 장면 개선, 기술 흐름 표시, 실제 읽기 연산 검증, 테스트, 기록 보존은 진행한다. GitHub 원격 게시·새 컨트랙트 배포·새 등록 거래가 이루어졌다고 주장하지 않는다.

## 선택 사항: 로컬 파일 선택 자동 검수

브라우저 자동화의 파일 선택은 ChatGPT 확장 기능의 로컬 파일 URL 접근 권한이 꺼져 있어 실행하지 못했다. 앱의 원본·변경본 샘플 선택과 실제 RPC 검증은 정상 동작했다. 이 권한은 데모 이용에 필요한 설정이 아니라, 에이전트가 로컬 파일을 자동 선택하는 검수를 위한 별도 권한이다. 사용자 승인 없이 확장 권한을 넓히지 않았다. 수동 파일 선택은 별도로 확인할 수 있다.

브라우저 도구의 안내:

> To enable file upload, open chrome://extensions, click Details under the ChatGPT browser extension, and enable "Allow access to file URLs." See [here](https://developers.openai.com/codex/app/chrome-extension#upload-files) for details.
